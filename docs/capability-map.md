# 能力地图：看哪里、补什么

课号与学习进度以 curriculum.json 和 tools/coach.py 为准。本页提供能力分组，不重新存储分数。`python3 tools/coach.py status` 查看课级记录；“小测通过”“作业待反馈”“反馈通过”各有不同含义。“看过”仅是学习者阅读标记，工具不自动检测。

| 能力 | 主讲课 | 证据 | 典型补练入口 |
| --- | --- | --- | --- |
| 交代与控制范围 | 01、14 | 明确任务、验收与变更取舍 | 提示返工→01；不断加需求→14 |
| 定位和接手 | 02、18 | 相关路径、可运行基线、优先级 | 盲读项目→02；混淆新旧缺陷→18 |
| 游戏实现与设计 | 03、04、15、16 | 可玩闭环、参数试验、视觉差异、模型验证 | 感觉说不清→04/15；数值无依据→16 |
| 持续协作 | 05、07、08、12 | 规则、可恢复提交、可复用流程、隔离任务 | 重复纠正→05/08；改动冲突→07/12 |
| 调试与性能 | 06、19 | 最小反例、必要回归、同条件测量 | 猜根因→06；盲目优化→19 |
| 功能复现 | 09、10、17 | 区分实验、独立规则与保留序列 | 把假设当事实→09；只拟合样例→10；忽略历史→17 |
| 成本与个人流程 | 11、20 | 同验收对比、完整失败成本、复查条件 | 只看回复长度→11；乱堆规则→20 |
| 数据与交付 | 21、22 | 兼容与恢复、干净包验收、反馈闭环 | 覆盖旧数据→21；本机可跑就交付→22 |
| 综合迁移 | 13 | 分级新任务与独立解释 | 找最低分项，再补对应主讲课 |

导师先看最低分维度和真实作业，不按“课程数完成百分比”推断能力。保留已有进度；工具不可用时用 workbook 的同一份作业记录手工反馈，不另建一套自动认证。
