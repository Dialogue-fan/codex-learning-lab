# 高效沟通速查

## 交代任务

目标（要改变的行为）＋上下文（文件/截图/复现）＋范围（保留什么）＋验收（如何证明完成）。不知道文件路径时请 Codex 定位，无需先自己读完项目。

差：帮我把游戏做得更爽。

好：玩家中弹后我希望更容易识别受击。参考现有玩家绘制，增加短暂闪烁；先不改伤害数值。验收：一次碰撞只扣一次血，闪烁结束恢复，重开后状态清零。完成相关验证，报告阻塞项。

## 纠偏

描述操作、实际结果、期望结果和保留项。例如：暂停后按重开，敌人速度变快；期望恢复初始速度；保留当前按钮布局。请复现后修正并验证。

## 模糊构想

“先用最多三个问题帮我明确核心玩法、第一版范围和验收，再给一个短计划。”复杂任务这样做；简单改文案无需完整访谈。

## 让 Codex 连续完成

允许定位文件、编辑本项目、运行相关检查并修复本次引入的问题；明确交付物和停止条件。影响外部用户的发布或数据修改按你的实际授权处理。提示词不会改变工具本身的权限。

## 分清四种信息

| 信息 | 位置 |
| --- | --- |
| 当次结果和验收 | 任务提示 |
| 稳定项目约定和命令 | AGENTS.md |
| 重复流程与触发条件 | SKILL.md |
| 进展、关键决策、未完成项 | 交接摘要 |

长期文件同样会被读取并消耗上下文；不要重复放同一段规则。不要要求输出逐步内心推理；要求简短决策依据和验证证据即可。
