# 零基础起步（30–60 分钟）

1. 文件：在项目里创建 workbook/00-profile.md，写一行自己的学习目标，再打开确认。
2. 终端：确认当前目录；运行 python3 --version（Windows：py --version）、node --version、git --version。缺少哪个就记录，不把错误当成功。
3. 项目：README 告诉你怎么运行；源码实现行为；测试检查一部分行为；版本控制保存变更。
4. Git：先理解 status 看改动、diff 看内容、add 选内容、commit 保存快照。clone 后再操作。不要把密码、密钥或整份私人日志放进作业。
5. 启动游戏：按 starter/game/README.md，访问本机地址；终端保持运行，结束按 Ctrl+C。

小测：改变游戏标题后，哪些证据说明改动生效？答案应包含实际打开页面，而不仅是文件已保存。将运行命令、看到的结果和一个仍不懂的点写进个人档案。

如果需要安装工具，请先让 Codex 确认你的系统，给出对应官方安装入口与最少步骤；不要照搬不匹配系统的命令。
