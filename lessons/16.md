# 16 · 游戏数值模拟与平衡

专题进阶 · 建议 90 分钟，可拆开完成。前置：04、06；会运行 Python 脚本。

## 本课目标

用明确模型与可重复模拟比较方案，再用试玩验证模型。

## 先答后看

平均伤害更高，是否一定更好玩？如果暴击有随机性，只跑一次战斗能下结论吗？

导师先等学习者回答，再根据误区讲解；不先代写最终作业。

## 核心概念

先定义决策和指标，再写模型：期望伤害、击杀时间、通关率、资源回收周期。模拟依赖假设，无法覆盖真实玩家操作与感受；固定种子便于复现，保留种子用于检验结论是否稳健。

## 互动实践

1. 定义玩具战斗：敌人生命 100，基础伤害 12，护甲 3，每秒攻击 2 次，暴击率 0.2、倍率 2。伤害先减甲保底 1，再暴击；首击发生在 0.5 秒。
2. 手算无暴击击杀所需次数与时间，作为模拟实现的基准。
3. 指挥 Codex 编写只用标准库的 Python 模拟，参数与规则分离；每个方案模拟 1000 局，记录种子。
4. 比较 A：基础伤害改为 14；B：暴击率改为 0.35。输出平均数、中位数和第95百分位击杀时间，并记录百分位算法。
5. 用不同种子复测，并检查零暴击、必暴击、高护甲等边界。把一个方案移植到游戏变体，邀请试玩，记录模型没覆盖的因素。

## 沟通示例

> 先根据规则手算一个无随机基准，再实现参数化模拟。输出可复现命令、种子、样本数、击杀时间分布和模型限制；不要只凭平均值宣布方案更好玩。

先写自己的版本，再比较这个示例。记录你为什么增删某条要求，不需要逐字照抄。

## 验收标准

基准手算吻合；种子可复现；样本与百分位定义明确；比较没有同时偷偷改变其他规则；有保留种子及试玩限制。

按 [五项评分](../docs/assessment.md)反馈；总分至少 8 且验证项非零，同时满足本课具体要求才建议通过。选择题不能替代实操。

## 三级提示与补练

一级：先不用随机数算攻击次数。二级：12 次攻击、每次间隔 0.5 秒，即 6 秒，是本例普通攻击基准。三级：示范循环后，独立增加掉落或资源经济模型。
