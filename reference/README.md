# 参考答案与常见错误

先完成自己的作业，再打开对应项。这里是最小判断依据，不是唯一实现，也不能替代本课具体验收。小测答案由 coach.py 检查；实操按证据与统一评分判断。

第06课有 [完整可运行示范](../examples/README.md)。其他条目提供作业对照要点；不是虚构的“标准项目已全部完成”。

<details>
<summary>第 00 课：作业后对照</summary>

参考方向：只确认当前入口和必需工具；记录实际命令与限制。

常见错误：误把缺一个工具当作必须安装所有集成。

返回 [本课](../lessons/00.md)，用一个新变体检验，而不是照抄后申报通过。

</details>

常见错误：只写风格词或锁死每行实现。
