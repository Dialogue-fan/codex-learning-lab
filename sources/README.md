## Academind 目录怎样融入本教案

- 入口、配置、权限、用量、会话与上下文：00、02、05、11。
- 提示、需求规格、计划、图片输入与反馈：01、03、04。
- AGENTS.md 与嵌套规则：05；先学准确短规则，再按项目需要扩展。
- Git、Worktrees、会话分叉：07、12。
- MCP、Skills：08；首次先做一个稳定流程，不堆工具。
- 测试、代码审查、浏览器验证：03、06、07、13。
- Cloud、自动化：12；作为手动流程稳定后的扩展。

两门来源的主题映射不表示它们逐课教授本仓库案例。游戏项目、逆向实验、评分与互动工具是新增教学设计。英语视频按需观看；先做作业，遇到概念再看对应片段。

## 如何选视频

优先看与当前问题匹配的一个视频或章节，而非连续看完所有内容。最短沟通路线：S8 作者教程→S6 视觉反馈→S4 中 Prompt & Context Engineering、Plan Mode、AGENTS.md、Feedback Loops。公开目录没有核实的章节时间戳不填写。

观看后写三行：一个可用方法、一个使用场景、一个实际验证结果。播放量和评分只提供受众信号，不证明能学会，也不证明节省 token。
