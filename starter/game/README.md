# 可玩起点：几何生存

原创几何占位素材，无第三方依赖。需要 Python 提供本地静态服务，浏览器支持 ES modules。

从仓库根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory starter/game
```

打开 http://127.0.0.1:8000 ，点击游戏区域，用 WASD/方向键移动；碰撞结束；按钮重新开始。远程开发环境使用其端口预览方式，本机地址可能不是你电脑地址。停止服务 Ctrl+C。

规则检查：`node --test starter/game/core.test.mjs`（Node 18+）。这些只验证逻辑，不代替页面玩测。

学习任务：第03课加暂停，第04课手感调参，第06课将复现方法迁移到游戏，第13课加新机制。起点没有暂停，不要误认为已有功能。
